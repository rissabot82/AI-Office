# Logs

## Purpose

This folder stores local system, agent, error, and audit logs.

## Structure

- agents: Activity generated by individual AI agents
- system: General AI Office application logs
- errors: Error reports and failure details
- audit: Important actions and change records
- archive: Older logs retained locally

## Git Policy

Operational log files are excluded from GitHub.

The folder structure and documentation may be committed, but generated log content should remain local.

## Security

Logs should never expose:

- API keys
- Passwords
- Authentication tokens
- Session cookies
- Full financial account numbers
- Sensitive customer information
