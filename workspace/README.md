# AI Office Workspace

## Purpose

The workspace is the operating area where assignments move through the AI Office.

## Workflow

1. inbox
   New requests and unprocessed assignments enter here.

2. active
   Work currently being handled by an agent or department.

3. review
   Work awaiting quality review or human approval.

4. approved
   Work that has been reviewed and approved.

5. outbox
   Work ready to be delivered, published, or transferred.

6. completed
   Finished work retained temporarily.

7. failed
   Tasks that could not be completed.

8. temporary
   Temporary processing files.

9. archive
   Older work retained locally for reference.

## Git Policy

Operational workspace contents are excluded from GitHub.

Only this documentation and placeholder files should be committed.
