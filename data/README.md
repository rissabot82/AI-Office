# Local Data

## Purpose

This folder contains information processed or generated by the AI Office.

## Structure

- input: Files waiting to be processed
- processed: Completed input files
- output: Generated results
- reference: Local reference material
- databases: Local database files
- exports: Data exported from AI Office
- imports: Data imported from external systems
- schemas: Safe data structure definitions
- archive: Retired local data

## Git Policy

Most operational data in this folder is intentionally excluded from GitHub.

Only documentation, schemas, placeholder files, and safe examples should be committed.

## Sensitive Information

Review files before moving them into this folder.

Do not commit:

- Customer information
- Lead information
- Financial account information
- Authentication information
- Personal identification data
- Private dealership records
