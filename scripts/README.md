# Scripts

## Purpose

This folder stores reusable scripts used to install, maintain, back up, monitor, and operate AI Office.

## Structure

- setup: Installation and initialization scripts
- maintenance: Cleanup and routine maintenance scripts
- backup: Backup and restoration scripts
- monitoring: Health-check and monitoring scripts
- utilities: General-purpose helper scripts
- migration: Data or system migration scripts

## Script Standards

Scripts should:

- Explain their purpose
- Validate required paths
- Handle expected errors
- Avoid deleting data without confirmation
- Avoid exposing credentials
- Produce understandable output
- Be safe to run more than once when practical
