# Tests

## Purpose

This folder stores tests that confirm AI Office components behave correctly.

## Structure

- unit: Tests for individual functions or components
- integration: Tests covering multiple connected components
- workflows: Tests for complete AI Office workflows
- fixtures: Safe example data used by tests
- results: Local test output

## Test Data Rules

Test fixtures must not contain:

- Real credentials
- Customer information
- Private financial information
- Personally identifying records
- Production API tokens
