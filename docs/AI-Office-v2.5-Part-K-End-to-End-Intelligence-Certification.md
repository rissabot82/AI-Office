# AI Office v2.5 Part K — End-to-End Intelligence Certification

Part K creates the release-level certification harness for the v2.5 Intelligence Upgrade.

It validates the complete installed intelligence stack:

- intelligence architecture;
- model inventory and benchmark harness;
- model quality benchmarking;
- benchmark-driven model selection;
- live local intelligence integration;
- intelligence operations;
- response quality control;
- quality escalation;
- external provider architecture;
- cost guardrails;
- local model availability;
- conversational runtime wiring;
- local fallback preservation;
- Discord operations availability.

## Paid API safety

A paid external API call is not required to structurally certify v2.5.

External activation can be tested separately after an API credential is deliberately configured.

## Certification output

Release certifications are persisted under:

`workspace/intelligence/certifications/`

The certification result records each check, pass/fail totals, and certification timestamp.
