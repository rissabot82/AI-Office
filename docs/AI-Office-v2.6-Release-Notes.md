# AI Office v2.6.0 - Memory & Context Integration

## Delivered
- durable memory architecture;
- persistent memory records and indexing;
- relevance-ranked retrieval;
- scope isolation;
- bounded context assembly;
- live conversational memory retrieval;
- memory-free fallback;
- memory operations and observability;
- explicit user-controlled durable-memory capture;
- final end-to-end certification.

## Safety
- automatic inferred memory capture remains disabled;
- explicit capture is required for user-approved conversation memory;
- secrets, tokens, and API keys are rejected from durable memory;
- memory is reference context, not instruction material;
- v2.5.1 prompt-leak, UTF-8, and poison-message protections remain preserved.
