# Local Backups

## Purpose

This folder may hold local backup copies created by AI Office maintenance scripts.

## Important Warning

A backup stored on the same computer is not a complete disaster-recovery solution.

Important backups should eventually be copied to a separate device or approved cloud location.

## Structure

- manual: Backups created manually
- automatic: Scheduled backup output
- configuration: Configuration backups
- databases: Local database backups
- archive: Older backups

## Git Policy

Backup contents are excluded from GitHub.

Do not use GitHub as the primary backup destination for private operational data.
